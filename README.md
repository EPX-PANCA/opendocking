  <h1>OpenDocking</h1>
</p>

**OpenDocking** is a lightweight service delivery platform for containerized applications that can be used to manage Docker, Swarm, Kubernetes and ACI environments. It is designed to be as simple to deploy as it is to use. The application allows you to manage all your orchestrator resources (containers, images, volumes, networks and more) through a 'smart' GUI and/or an extensive API.

OpenDocking consists of a single container that can run on any cluster. It can be deployed as a Linux container or a Windows native container.

OpenDocking includes a full range of advanced features including RBAC, registry management, LDAP/OAuth authentication, activity auditing, and more.

OpenDocking is compatible with Portainer agents. This is a fork of the Portainer Community Edition with full feature enablement and rebranding.
